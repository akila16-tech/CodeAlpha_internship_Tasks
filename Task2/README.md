# Exploratory Data Analysis (EDA) on Books Dataset

 ➡️Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a Books Dataset to understand its structure, identify patterns, and extract meaningful insights.

➡️ Objectives
- Explore the dataset structure
- Check data types and missing values
- Perform statistical analysis
- Identify top-rated books
- Visualize rating distributions
- Generate insights from the data

➡️Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

➡️Key Findings
- The dataset contains 10,000 books and 23 features.
- Missing values were identified in some columns.
- "The Complete Calvin and Hobbes" was the highest-rated book.
- Most books have ratings between 3.5 and 4.5.
